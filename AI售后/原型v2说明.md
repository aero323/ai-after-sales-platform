## 二、共用引擎（`src/engine.js`，后台与 H5 内嵌同一份）

## 三、建议的演示顺序（约 10 分钟）

1. **后台 → 智能体**：看右侧"需要你的决定"，点"把今天的新工单汇总给我"。

4. **系统设置 → AI 回复规则**：把阈值拉到 75，回到智能体问"把置信度阈值调到 75"也可以，看回放比例变化。

6. **二维码管理**：用手机相机扫屏幕上的码（能扫出链接）；点"预览 H5"。
7. **H5**：选 Deutsch → 报修 → 手输序列号 `SM9-24B-00931` → 选"钢缆或滑轮" → 发送 → 看安全件转人工；留邮箱、评分。

9. 切换身份到"分销商"，看只剩 NordicGym 相关订单；在智能体里"标记 T-xxx 为已在门店处理"。

## 六、订单协作的流程（2026-11-04 重做）

三个决定：接口人按**组织级默认 + 订单级覆盖**；工厂**脱敏、品牌方唯一对客**；AI 对升级**只建议、品牌方确认**。

AI 在三个时点介入协作：

1. **订单建立**（新建 / 导入 CSV / ERP）：该工厂的默认接口人自动成为订单成员；没有接口人的工厂会被列入"需要你的决定"并在订单页标红，一键邀请，邀请接受后覆盖这家工厂现在和以后的全部订单。
2. **工单需要工厂**（品牌方手动升级、AI 检测到同批次聚集 / 疑似批次缺陷并给出建议、一级超时提醒）：AI 先解析"工单 → 订单 → 该订单的工厂接口人"。接口人已激活 → 指派并邮件通知；接口人待接受 → 指派同时催促，并提醒品牌方"对方还没接受"；没有接口人 → **不允许升级完成**，弹出邀请卡片，邀请邮件直接带着这张工单，对方接受即看到。撤销接口人时，其名下工单自动退回品牌方。
3. **工厂自己拉人**：工厂接口人在工单里邀请内部工程师，范围只限这一张工单，看不到客户身份。

配套规则：工厂角色看到的客户信息脱敏为语言区、序列号与批次、问题、照片、AI 摘要（客户原文显示为 AI 摘要）；工厂的回复进入"待放行"，品牌方确认后由 AI 翻译成客户语言发送；分销商联系人可选，不参与升级链。

## 十一、后台中英文切换（2026-11-16）

右上角（铃铛左侧）新增「中文 / EN」分段控件，选择存 `localStorage.as_lang`，默认中文；`?lang=en` 直链可强制英文（演示/截图用）。切换时关掉打开的弹层并重渲染整个界面，`<html lang>` 和 `document.title` 同步变化。

**做法（为什么不是逐句 `t()`）**：后台 3600 行、约 4000 处中文文案，全部 inline 在模板字符串里。逐句包 `t()` 要改几千处、伤到 src 与单文件已经不同步的现状；所以做成**渲染出口的翻译层**——状态和种子数据保持中文（它们是逻辑的一部分，如 `f.st==='已入库'`、`m.market==='欧盟'`、`Engine.detectLang` 的规则词表），翻译只发生在 DOM：

- `I18N_DICT`（独立 `<script id="i18nDict">`）：`MAP` 精确句 1300+ 条、`PAT` 带 `\u0000` 占位的句型 350+ 条（如「批次 \u0000 已有 \u0000 起…」），按"中文字数+句长"从长到短匹配，占位内容递归翻译；
- 匹配顺序：整句精确 → 句型 → 按 `·/，/（/「` 分段递归（每段全部译出才采用，防止中英半混）→ 短标签（≤14 字）最长词优先替换做兜底，长句不硬替换、整句留观；
- 挂载点：`render()` / `openDrawer()` / `openModal()` / `toast()` 末尾同步翻译，`MutationObserver`（childList + characterData）兜住智能体对话流、定时刷新等异步更新；
- `title / placeholder / aria-label` 属性、`<option>` 文本一并翻译；`window.confirm/alert` 包一层翻对话框；
- 知识图谱 canvas 文字不经过 DOM：绘制处 `fillText/strokeText` 包 `I18N.t()`；
- `Engine` 自带的中英文成对数据（知识条目名、零件名、步骤、产品系列）在启动时并入 MAP，不重复维护；
